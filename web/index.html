RENPHO relay installer

Install and set up the relay on a Waveshare ESP32-S3-LCD-1.47 from this browser. Firmware version: loading.

This browser cannot use USB serial ports. Use Chrome or Edge on a computer.

Connect the board with a USB data cable. Each button asks you to select its port. Everything happens in this browser: the page sends your settings only to the board, over USB.

1. Back up the board

Before the first installation, save the current flash contents (16 MB). This takes a few minutes. Keep the file private.

2. Install the firmware

Writes the relay firmware. It does not erase the board, so an update keeps your settings and stored readings.

4. Check the relay

Shows whether the relay is configured, on Wi-Fi, and paired with a scale. Step onto the scale to pair it.
